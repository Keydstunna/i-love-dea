# For Dea 🌸 (React + Vite)

    npm install
    npm run dev        # open the link it shows
    npm run build      # makes the /dist folder

Put your files in `public/`:
- `photos/dea.jpg`, `photos/1.jpg` … `photos/6.jpg`, `photos/funny.jpg`
- `covers/love.jpg`, `daylight.jpg`, `tibok.jpg`, `get-you.jpg`, `pangarap-lang-kita.jpg`
- `music/love.mp3`, `daylight.mp3`, `tibok.mp3`, `get-you.mp3`, `pangarap-lang-kita.mp3`

Edit all words, dates and songs in `src/data.js`.

Render (Static Site): Build Command `npm install && npm run build`, Publish Directory `dist`.
